Problem Statement
The client manages executive education programs for the energy sector using event schedules and agendas that were manually created by different people over several years. Because the files have different formats, the information is difficult to organize, search, update, and analyze. The product should provide a more organized and consistent way to manage this event information.
Goals
The product should:
Organize information from past and current event schedules into a consistent format.
Make event information easier to search and access.
Allow authorized users to add, edit, and delete records.
Support analysis of the event data.
Provide backup and restore capabilities.
Help users create new event schedules using organized information.
Constraints
The product must work with existing event schedule and agenda information.
The existing data comes from files created by different people and may use different formats.
The product should support data from the client's executive education programs.
The initial product should focus on the requirements identified by the client rather than adding unrelated features.
The product should allow the existing information to be organized without requiring the client to recreate all of the historical data manually.
Target Users / Personas
Program Staff
Program staff manage the executive education programs and need to organize, update, and maintain event information.
Event Planners
Event planners need to use information about sessions, speakers, locations, times, and other event activities to build new event schedules.
Program Analysts
Program analysts need to search and analyze historical event information to find useful information across past programs.
User Stories
As a program staff member, I want to add event information so that new records can be stored in the system.
As a program staff member, I want to edit existing records so that incorrect or outdated information can be updated.
As a program staff member, I want to delete records so that information that is no longer needed can be removed.
As a user, I want to search event information so that I can quickly find relevant records.
As an analyst, I want to analyze historical event information so that I can identify useful patterns and information.
As an event planner, I want to use organized event information to create a new schedule so that I can plan future events more efficiently.
As a program staff member, I want to back up and restore data so that important event information can be recovered if necessary.
Functional Requirements
The product must:
Store event information in an organized and consistent format.
Allow users to add new records.
Allow users to edit existing records.
Allow users to delete records.
Allow users to search stored event information.
Support analysis of stored event information.
Provide a way to back up stored data.
Provide a way to restore backed-up data.
Support the creation of new event schedules.
Preserve important information from existing event schedules, including information such as event dates, times, sessions, speakers, locations, and other scheduled activities.
Out of Scope
The initial product will not attempt to solve problems unrelated to organizing and managing the client's event information. Features or capabilities that are not necessary for organizing, searching, editing, analyzing, backing up, restoring, or creating event schedules will be deferred until the client identifies a specific need for them.
